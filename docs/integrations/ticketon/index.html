Ticketon Integration

Connects Ticketon with the Newo AI agent so callers can search events, choose the right city, hear session details, and receive a selected event page link by WhatsApp.

Before You Start​

Make sure you have:

  • access to Newo Builder for the project, with permission to edit module settings and click Publish All;
  • the Ticketon connector available in the project;
  • TalkMe WhatsApp sender settings configured in the connector if you want the agent to send event links by WhatsApp.

Ticket purchase, seat selection, payment, refunds, and ticket cancellation are not handled by this integration. The agent discovers events and sessions, then hands the caller off to the Ticketon event page.

What the AI can do​

  • Search Ticketon events. The agent can search by event name, movie title, category, date phrase, and city.
  • Resolve cities before lookup. The agent asks for a city before searching and uses Ticketon's city vocabulary to map the answer.
  • Present event options. When several events match, the agent lists numbered choices and waits for the caller to pick one.
  • Fetch session details. The agent reads event sessions, venue, time, language when available, price, and on-sale status.
  • Handle cinema separately. For movies, the agent asks for a specific date before looking up sessions.
  • Send WhatsApp links. After a selected event has an on-sale session and the caller confirms the destination phone number, the agent can send the event page link through WhatsApp.

Setup​

1. Prepare Ticketon and TalkMe​

The Ticketon API access and TalkMe delivery credentials live in the Ticketon connector settings, not in the Ticketon module attributes.

For event discovery, confirm the connector has the default Ticketon settings for language and country. For WhatsApp delivery, configure the approved TalkMe sender and token before enabling link delivery for live callers.

2. Configure in Newo​

  1. Open the project in Newo Builder.
  2. Find the Module - Ticketon settings group.
  3. Keep Enable event discovery on when this project should answer Ticketon event questions.
  4. Keep Enable WhatsApp link delivery on only when TalkMe delivery is configured.
  5. Keep Install Ticketon scenarios on unless support is maintaining a custom canvas manually.
  6. Click Publish All.

3. What Publish All does​

After Publish All, the integration:

  • creates or starts the Ticketon connector;
  • registers the event search and WhatsApp link tools;
  • refreshes the Ticketon city vocabulary;
  • publishes the Event Discovery intent and scenario when scenario setup is enabled.

How to test that everything works​

Test event discovery​

  1. Ask the agent: "Find concerts in Almaty this weekend."
  2. The agent should ask for the city only if it was missing, then say a short immediate promise in the user's language whose meaning is: "I will look for matching event options now."
  3. The agent should return event options or session details from Ticketon, not answer from general knowledge.

Test cinema sessions​

  1. Ask the agent: "What time is this movie showing in Astana?"
  2. If the date is missing, the agent should ask for the preferred date.
  3. After the date is provided, the agent should say a short immediate promise in the user's language whose meaning is: "I will look for matching event options now."
  4. The agent should present movie sessions for the selected city and date.

Test WhatsApp link delivery​

  1. Complete an event lookup until the agent presents sessions and offers to send the link.
  2. Ask it to send the link by WhatsApp.
  3. Provide and explicitly confirm a full destination phone number.
  4. The agent should say the WhatsApp send code-phrase in the user's language: "Give me a moment to send the event link to WhatsApp right now. I'll get back to you shortly."
  5. The agent should confirm delivery only after the delivery result is available.

Why trigger phrases matter​

The scenario contains required code-phrases the agent must say at specific steps in the user's language. Those code-phrases trigger the integration tools. If you edit the scenario, preserve the required meaning and phrase-only behavior.

Scenario 22 - Event Discovery​

Runs when the caller asks about Ticketon events, movies, concerts, theatre, circus, sports, museums, master classes, session times, venues, prices, or WhatsApp delivery of the selected event link.

  1. Critical step: ask what event, movie, show, or category the caller is looking for.
  2. Critical step: ask which city to search in before lookup if the caller did not already name one.
  3. Critical step: trigger event discovery with a short immediate promise in the user's language whose meaning is: "I will look for matching event options now."
  4. Wait for the event lookup panel and react to its state: loading, options, needs date, needs city, unavailable, no sessions, success, or error.
  5. If the caller wants WhatsApp delivery, confirm that the selected event has a link and on-sale sessions, collect and confirm the destination phone number, then trigger delivery with the WhatsApp send code-phrase: "Give me a moment to send the event link to WhatsApp right now. I'll get back to you shortly."

Triggered by intent: Event Discovery.

Trigger code-phrases (preserve required meaning and phrase-only behavior):

  • "I will look for matching event options now." - fires event discovery and session lookup when said as a short immediate promise in the user's language.
  • "Give me a moment to send the event link to WhatsApp right now. I'll get back to you shortly." - fires WhatsApp link delivery when said in the user's language.

What the agent reads to know the result:

  • Ticketon cities panel - city vocabulary refreshed from Ticketon; used to map caller city names to stable city codes and ids.
  • Event lookup panel - current event lookup, selected event options, required next detail, sessions, event link, WhatsApp sending state, or error.

Safe customization:

  • Change greeting, tone, and language around the trigger code-phrases.
  • Add business-specific transfer wording for unsupported purchase, refund, or cancellation requests.
  • Do not add city names, event titles, links, explanations, or questions to either code-phrase.
  • Do not remove the city step before event discovery.
  • Do not promise ticket purchase or seat reservation.

FAQ​

Q. Does the agent buy tickets? No. It gives event/session information and can send the Ticketon event page link. The caller completes purchase on Ticketon.

Q. Why does the agent ask for a city before search? Ticketon search and session lookup are city-sensitive. The city lets the integration pass the right location filter and session city id.

Q. Why does cinema need a date? Movie sessions are date-scoped. The agent asks for a date before retrieving cinema sessions.

Q. Can WhatsApp delivery work without TalkMe settings? No. The module toggle only enables the feature in Newo. The connector still needs the TalkMe API key and approved sender/source.

Q. What happens if the city cache is empty? The agent still asks for the city. The session lookup will try to resolve the spoken city through the connector and will ask again if it cannot resolve it.

Common errors and recovery​

The agent does not run event search after the scenario was edited​

Likely cause: the event discovery code-phrase was changed, extended with extra text, or removed.

How to recover:

  1. Open the Event Discovery scenario on the canvas.
  2. Restore the event lookup promise meaning: "I will look for matching event options now."
  3. Click Publish All.

How to verify: ask for an event again; the event lookup panel should move to loading, options, success, or a recovery state.

WhatsApp link is not sent​

Likely cause: TalkMe settings are missing, the selected event has no on-sale sessions, the event link is missing, or the phone number was not explicitly confirmed.

How to recover:

  1. Confirm Enable WhatsApp link delivery is on.
  2. Confirm the connector has talkme_api_key and talkme_source configured.
  3. Run an event lookup until the event lookup panel is in success with an event link and available seats.
  4. Ask for WhatsApp delivery again and confirm the full phone number.

How to verify: the event lookup panel should move through whatsapp_sending to whatsapp_ready.

The agent keeps asking for city​

Likely cause: the city name did not resolve to a Ticketon city id.

How to recover:

  1. Ask the caller for a more specific city name.
  2. Use a major Ticketon city name when testing, such as Almaty or Astana.
  3. Click Publish All if the city vocabulary was not refreshed recently.

How to verify: the next lookup should proceed to event options or sessions instead of needs_city.

Limitations​

  • Ticket purchase, payment, seat selection, refunds, and ticket cancellation are outside the integration.
  • WhatsApp delivery sends the event page link, not a ticket or payment link generated by Newo.
  • Session lookup uses the connector list_sessions dispatcher for both cinema and non-cinema events.
  • One lookup uses one Ticketon city at a time.
